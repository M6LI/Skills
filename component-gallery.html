Parameter design rules

C14 · C26 · C30

Use typed numerical inputs, model-specific field descriptions, and a separate execution action if recalculation is expensive. An identical parameter sheet must not appear for OLS, Ridge and XGBoost.

  • Ridge: regularisation α and standardisation.
  • XGBoost: max depth, number of trees, learning rate.
  • Neural network: hidden width, depth, optimiser and epochs.
